# Sunrise PDF Editor — Web Edition

Sunrise PDF Editor Website v4.5.0 R02 개발본. 첨부된 R00 웹사이트 ZIP을 기준으로 홈(`dist/index.html`)과 PDF 편집기(`dist/editor/index.html`)를 유지한다. 본 웹 프로젝트는 기존 Windows 제품 및 Sunrise Control을 수정하지 않는다.

## 실행 및 구성

- 정적 호스팅 루트: `dist/`; 첫 화면 `/`, 편집기 `/editor/`.
- PDF 데이터는 브라우저 내에서 처리하며 PDF 전송 API나 서버 저장소는 사용하지 않는다.
- PDF.js 5.6.205(legacy 빌드, Apache-2.0) 및 pdf-lib 1.17.1(MIT)을 `dist/assets/`에 포함한다. 라이선스와 CMap·표준 글꼴·WASM 리소스도 함께 포함한다.
- 화면용 Google Fonts 및 Font Awesome은 여전히 외부 CDN을 사용할 수 있다. 브라우저/네트워크 환경에 따라 해당 글꼴·아이콘은 달라질 수 있다.
- 로컬 확인 시 `dist/`를 웹 서버의 루트로 제공한다. 절대 경로(`/assets/`, `/editor/`)를 사용하므로 단일 HTML을 직접 `file://`로 열지 않는다.

## 현재 기능 범위와 주의사항

- 암호 보호 PDF는 편집을 거부한다. 암호화 저장, 보안상 완전한 정보 삭제는 지원하지 않는다.
- 입력 PDF는 50 MiB 이하로 제한한다. 생성한 결과 PDF는 다른 이름의 다운로드로 제공한다.
- 텍스트·머리말·꼬리말·페이지 번호는 검색 가능한 글자로 저장한다. 저장한 PDF를 이 편집기에서 다시 열면 삽입 항목을 복원하여 수정할 수 있다. 다른 프로그램이 편집 정보를 바꾸거나 제거한 파일은 복원이 불가능할 수 있으며 원래 표시는 유지한다.
- 표·주석·스탬프 등은 이미지로 합성된다. 원본 PDF의 콘텐츠와 복잡한 양식·서명은 개별 문서 검증이 필요하다. 일부 특수 문자와 이모지는 저장 글꼴이 지원하지 않을 수 있으며 이 경우 저장을 중단하고 알린다.
- 한글 글꼴 Droid Sans Fallback은 Android Open Source Project의 Apache-2.0 글꼴이다. 글꼴 원본 SHA256: ee38813ea00c3e32add4268fff7fff9e39417b4913cb13be2415164a47807cc2. 라이선스는 `dist/assets/fonts/`에 포함한다.
- 페이지 순서 변경은 모든 페이지 번호가 정확히 한 번 포함될 때만 허용한다. 삽입 항목이 있는 페이지의 회전은 결과를 저장하고 다시 열어야 한다.
- 열린 문서를 병합할 때 페이지 위 삽입 항목도 합성한다. 병합 결과에는 원본의 문서 수준 북마크와 첨부파일이 포함되지 않는다.
- 북마크 패널에 추가한 페이지 표시는 현재 편집 세션에서만 사용한다. PDF 북마크 기록 및 목차 자동 분석은 아직 지원하지 않는다.
- 기존 PDF의 첨부파일은 읽어 표시할 수 있다. 새 첨부는 기존 첨부파일이 없는 문서에만 추가할 수 있고 저장 결과에 포함된다. 기존 첨부가 있는 문서에 추가하는 동작은 차단한다.
- 기본 정보 비교는 페이지 수를 비교하며 실제 본문·이미지 차이를 분석하지 않는다. 내장 원본 이미지 추출, 검색된 원문 위치에 하이라이트, 보안 편집은 미지원이다.
- 회사 PC의 무문서 빌드 정책은 Windows 제품의 정책으로 유지되며 이 사이트가 회사 문서를 자동 열거나 검사하지 않는다.

## 개발 검증

`node tests/synthetic-contract.cjs`는 실제 PDF 엔진과 편집기 함수로 페이지 항목의 재배치, 복제 ID, 빈 페이지 위치, PDF 결과 생성 및 신규 첨부 직렬화를 검사한다. `SUNRISE_TEST_PDF` 환경변수를 설정하면 테스트 결과 PDF를 해당 경로에만 남겨 외부 PDF 파서로 추가 확인할 수 있다. 실제 사용자 문서는 사용하지 않는다.

검증 범위 및 남은 항목은 `VALIDATION.md`를 따른다. 공개 배포를 위한 품질 인증이나 Windows 데스크톱 검증을 주장하지 않는다.

## 공개 배포물 준비

- 편집기와 자체 스크립트의 읽기 쉬운 원본은 `src/`에 보관하고, `npm ci && npm run build`로 축소된 `dist/` 파일을 생성한다. 테스트와 빌드 도구, 원본은 정적 호스팅 대상이 아니다.
- `npm test`는 원본의 핵심 함수와 실제 배포용 글꼴·편집상태 모듈을 검증한다. 브라우저의 축소 코드 동작은 별도로 확인한다.
- 축소는 이해와 분석을 어렵게 할 뿐 코드 공개를 막지 않는다. 비밀값은 브라우저에 제공하는 파일에 넣지 않는다.
- 외부 글꼴·아이콘 CDN에 대한 요청은 계속 발생한다. PDF 본문은 사이트의 PDF 전송 API로 보내지 않도록 구성되어 있으나, 외부 CDN과 방문자의 브라우저·확장 프로그램에 대한 별도 보안 보증은 아니다.
- 배포 전 점검 결과 및 제한은 `PUBLIC_RELEASE_AUDIT.md`를 따른다. `dist/assets/`의 라이선스 문서는 배포 대상에 의도적으로 유지한다.

## 보기와 단축키

편집기 상단의 페이지 보기에서 연속·한쪽·두쪽·세쪽을 선택한다. 스크롤이나 페이지 클릭으로 현재 페이지가 바뀌면 좌측 페이지 선택도 따라간다. Ctrl+2는 한쪽 보기이며, 사용 가능한 PC 단축키는 리본 버튼 설명에서 확인할 수 있다. 브라우저가 우선 처리하는 조합 대신 텍스트 삽입은 Alt+Shift+T, 문서 닫기는 Alt+Shift+W, 순서 변경은 Alt+Shift+R을 사용할 수 있다. 브라우저 및 운영체제에서 가로채는 키는 웹에서 강제할 수 없다.

## Cloudflare Workers 배포

`npm ci && npm test && npm run build` 후 `npx wrangler deploy`를 사용한다. Git 연동 시 지정된 배포 브랜치에 한해서 배포한다. 비공개 저장소라도 브라우저에 제공되는 정적 파일은 방문자가 볼 수 있다.
