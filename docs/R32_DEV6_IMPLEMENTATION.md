# R32-DEV6 — 기능 3종 배치 개발 인계

## 변경 소스
- `src/assets/sunrise-special-pdf.js`: `reviewSensitiveTextCandidates({pages,plan})` 신규. 주민번호형식·휴대전화·이메일·사업자번호 텍스트 후보를 스캔하고 지정된 마스크 전체 안에 위치하지 않는 후보의 쪽 번호와 건수를 반환. 개인정보 원문은 결과에 기록하지 않음. OCR 없음.
- `src/editor/index.html`: 마스킹 모달에 후보 탐색·검토 체크박스 추가, 검토 없이 내보내기 방지, 마스크/출력 범위 변경 시 재검토 강제. 기존 PDF 상태 보존 스냅샷으로 북마크·오버레이·메타데이터·첨부 변경 시 중단.
- `src/assets/sunrise-office-export.js`: `docxTwoColumn` 별도 선택 기능. 좌·우 단 경계와 최소 3줄 조건이 충족되는 PDF에 한하여 2열 Word 표로 편집 가능한 단을 구성. 경계 교차나 제목·페이지 구조 모호성은 즉시 거부.
- `src/editor/index.html`: Word 두 단 변환 메뉴, 도구 실행 명령, 파일명·MIME·고지 문구 연결.

## 중요한 한계
1. 마스킹 개인정보 후보는 텍스트 아이템별 정규식 탐색만 수행하고, 이미지 안의 개인정보·조각난 문자열·기타 유형을 찾아내지 못함. 후보가 없어도 완전 삭제를 의미하지 않음. PDF.js 좌표는 근사치이므로 보수적으로 마스크 전체에 포함되는 경우에만 가림으로 판정.
2. 2단 Word는 가운데 일정한 여백이 존재하는 정규 두 단 PDF용. 모든 단에서 3줄 이상 필요하고 가운데를 가로지르는 머리글/문단이 있으면 중단. 그림·원본 표·복잡한 텍스트 배치 복원 미지원.
3. 자동화/빌드/Node/브라우저 테스트 및 GitHub/Cloudflare 변경 **없음**. 이전 `dist/`는 여전히 구형 산출물.

## 이후 우선 개발
1. USR-14 QPDF WASM 패키지 확보·실제 AES-256 생성/해제, 잘못된 암호 실패, 외부 PDF 뷰어 검증 (별도 실행 허가 필요).
2. USR-15 CMS/ByteRange 독립 PDF 뷰어 상호운용·P12 및 인증서 신뢰검증 확장.
3. USR-05 CID/한글과 복합 Tj/TJ 안정적 편집, USR-16 복합 표/이미지 구조 및 다단 문서 개선.
4. USR-13 이미지 개인정보 수동 누락 검토 보강 및 마스킹 결과 재열기 검증.
