# R23 — 전문 PDF 2개 기능 묶음 개발

기준: 2026-10-31 v1.2 확정 개발계획, OCR 제외. R22의 작업을 이어받는다.

## USR-13: 민감정보 마스킹 픽셀 경계

PDF.js가 렌더한 페이지에서 소수점 마스킹 좌표를 래스터 픽셀로 변환할 때 종전 `floor(x*scale), ceil(width*scale)` 조합은 마스크의 오른쪽/아래쪽 끝부분에서 최대 1픽셀을 덜 칠할 수 있었다.

R23은 `floor(x*scale)`부터 `ceil((x+width)*scale)`까지 정확히 커버하도록 **두 출력 경로 모두 수정**했다. 단일 페이지 `exportMaskedPage`와 다중 페이지 `exportMaskedPages` 회귀검사에 `x=11.35, y=20.45, width=50.85, height=40.65`를 추가하여 2배 렌더 크기의 좌표 `(22,40,103,83)`을 확인한다.

이는 지정된 사각형 경계에서의 픽셀 누출을 방지하는 수정이다. 문서 전체의 민감정보 탐지, 모든 숨은 객체의 보안 인증 또는 사용자가 입력하지 않은 사각형 외 정보의 삭제는 보증하지 않는다. 마스킹 방식은 여전히 전체 이미지 래스터 출력이며 원본 PDF의 텍스트·첨부·주석을 복제하지 않는다.

## USR-16: PDF 텍스트 좌표 기반 Excel 열 추정

원래 `exportExcelText` 메뉴와 2열 '페이지/텍스트' 변환을 그대로 유지하고, **새로운 별도 명령 'Excel 표 열 추정 (정렬된 표)'**을 추가한다. 텍스트가 동일 기준선에서 규칙적으로 반복되는 PDF 표에 한해, PDF.js의 텍스트 `transform` 및 `width`를 이용해 페이지별 가로 열을 추정하고 XLSX 열로 출력한다.

- PDF에서 가져온 페이지·텍스트의 실제 텍스트 값을 `inlineStr`로 저장해 수식 텍스트가 실행되지 않게 한다.
- 동일 기준선 정렬, 2행 이상에서 일치하는 2개 이상 가로 열(좌표 차 ±18pt)을 요구한다. 최대 10개 열, 최대 120쪽, 기존 2MiB 텍스트/3만 행/셀 32,767자/결과 12MiB 보호 제한을 재사용한다.
- 규칙적인 열이 없으면 기존 Excel 텍스트 내보내기를 이용하도록 안내한다. 불규칙한 다열 좌표·회전 텍스트·충돌하는 셀은 잘못된 파일을 조용히 만드는 대신 거부한다.
- 표 외의 텍스트 한 줄도 버리지 않고 Excel의 첫 데이터 열에 보존한다. 페이지별 번호를 별도 열로 기록한다.
- 표 테두리·병합 셀·원본 수식·이미지·스타일 복원 및 완전한 PDF 표 인식은 수행하지 않는다.
- 단위검사로 실제 XLSX ZIP·2열 대응·페이지 번호·수식형 텍스트 이스케이프·불규칙 좌표 거부를 확인하고, 브라우저 PDF 실제 열기 → `exportExcelColumns` → `_columns.xlsx` 다운로드/ZIP 검사까지 연결했다.

## 통합·배포

R23은 R22 위에 추가한 stacked PR이다. 운영 `main`/Cloudflare/D1/실사용 자료를 변경하지 않는다. 전 기능 자동 CI, Chrome·Edge·Chromium 회귀 후 구현·자동검증 수치만 보수적으로 갱신한다. 실제 고객 PDF·Windows Office·Android/iOS 실기기 수용·최종 운영 배포는 별도다.
