## 실제 코드 작성 내역 (이번 연속 브랜치)

- **USR-07**: 표준 PDF Text/Highlight 문서 전체 목록·검색·페이지 이동·수정/삭제, 공유 객체·연결 주석 차단, 검토 의견표 CSV에 원본 메모/형광펜 통합. CSV 다중 실행 방지 및 문서 상태 변경 보호. 기존 원본 보존/Undo 유지.

- **TECH-01**: 주석 열람/CSV에서 전체 PDF 바이트 복제를 생략하는 읽기 전용 저장 상태 캡처, 연속 브랜치 CI 게이트 분리.

## 안전 및 종결 게이트

- USR-05 원문 내용 스트림 직접 변경은 현재 **시각 교정만** 구현; 원문 자체가 남아 검색·추출될 수 있음을 명확히 표시한다.
- USR-13 민감정보 완전 삭제는 별도의 노출·픽셀·재검색·추출 검사를 완료하기 전 '완전 삭제'로 주장하지 않는다.
- USR-14 웹 브라우저용 AES-256은 아직 없음(로컬 QPDF 도구만 있음); 브라우저 지원 여부는 별도 엔진·보안 검증 필요.
- USR-15 인증형 디지털 서명은 아직 없음(시각적 표시만 있음); 인증서·개인키 처리 개발 없이는 완성으로 기록하지 않는다.
- USR-16 Word·Excel은 텍스트 중심 변환이며 표/서식/이미지 완벽 복원 아님. 검증 범위/실제 Office 확인 후 지원 정책 확정.
- QA-01 및 REL-01은 최종 자동·수동 검증과 실운영 승인 이전에 완료 처리 금지. CI 실행 시 실패/부적합 사항을 우선 해결한다.
