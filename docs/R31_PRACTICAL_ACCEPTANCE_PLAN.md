# R31 사용자 실기검증 체크리스트 — 실행 전 계획서

*현재는 실행하지 않음. 사용자가 실기검증을 지시할 때에만 적용합니다.*

## USR-07 주석·형광펜
- 메모·하이라이트 원본 주석 수정 후 저장하고 새로 열어 수정된 내용만 남는지 확인.
- 수정하지 않은 텍스트, 잘못된 Unicode, 연결 주석, 주석이 공유된 PDF는 거부되는지 확인.
- 주석 삭제 후 실제 PDF를 다시 열어 제거됐는지 확인. **민감정보 완전 삭제라고 오해하지 않기**.

## USR-08 북마크·목차
- 1~4단계 한글 북마크를 추가하고, 다른 이름으로 저장 후 제목·계층·페이지 대상이 그대로인지 확인.
- 기존 북마크가 있는 문서에 새 북마크 추가할 때 이전 북마크가 그대로 남는지 확인.
- 잘못된 목적지/링크/중복 참조 PDF는 조용히 손실시키지 않고 오류를 알리는지 확인.

## USR-09 PDF 압축
- 무손실(0)과 저·중·고 설정을 비교: 실제 파일 크기, 텍스트 검색, 페이지 기하, 양식 상태, 투명 이미지 경계/문자 품질.
- 압축 전후 용량이 증가하지 않는지, 원본이 보호되는지 확인.

## USR-10 PDF 양식
- 한글 텍스트·체크박스 5개 이상을 한 번에 수정, 출력본에서 값/체크 상태가 동일한지 확인.
- 필수·읽기전용·기존값 보존 및 Undo 확인.

## USR-11 PDF 일괄 처리
- 최대 5개 PDF 워터마크와 페이지 번호: 각 다운로드 결과와 표시된 원본·출력 크기 확인.
- 작업 도중 취소, 재시작, 실패 PDF 혼합 시 성공/실패 건수와 결과 다운로드 범위 확인.

## USR-12 제출 전 품질 검사
- 빈 페이지·혼합 세로/가로·누락 필수 필드·XFA/서명 경고 확인.
- 경고 120건 초과 합성 문서에서 실제 오류·검토 건수가 누락되지 않고 요약 안내가 표시되는지 확인.
- OCR·PDF/A·전자서명 유효성은 검사 범위가 아님을 확인.

## 최종 판정

각 기능에서 실제 테스트 파일 다운로드·재열기 및 눈으로 확인한 사용성을 기록합니다. 사용자 승인 전에는 **PASS·100%·배포 가능** 판정을 하지 않습니다.
