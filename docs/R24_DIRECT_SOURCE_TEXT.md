# R24 — USR-05 PDF 원문 텍스트 직접 수정
기존 시각 교정 오버레이와 구분해 단일 PDF Tj 내용 스트림의 ASCII 원문 텍스트를 직접 변경하는 기능을 추가한다.
지원: 표준 Base-14 Type1 글꼴, ASCII 1~120자, 동일 글자 수 교체, 현재 쪽에서 고유한 일치 하나, unfiltered/Flate PDF 스트림.
거부: 중복 원문, 서명·양식, 복잡한 글꼴·조합 텍스트·한글, 공유 스트림. 512KiB 원문 및 2MiB 해제 텍스트 제한.
실제 PDF.js 텍스트 검증 이후에만 Undo 스냅샷과 문서를 갱신한다. 원본 입력은 수정하지 않는다.
이는 민감정보 완전 삭제가 아니다. 다른 객체·메타데이터·첨부에는 원문이 남을 수 있다.
Node/브라우저 E2E를 통해 실제 텍스트 수정·저장·재열기·Undo를 검증한다. 고객 파일·한글·모바일 실기는 미검증.
