# R32-DEV8 — 다중 미완성 기능 배치 개발

기준: 사용자가 확보한 R26 전체 소스를 R32로 통합하고, DEV1~7 코드를 반영한 실제 프로젝트 전체 소스.

## 이번 차수 실제 제품 소스 변경

1. **USR-05** `src/assets/sunrise-special-pdf.js`: 기존 단일 `Tj` 외에, 표준 Type1/WinAnsi 문자열이 여러 구간으로 나뉜 제한적 `TJ` 배열 편집. 원본의 숫자 간격 조정값 보존, 바이트 길이·폰트·중복 대상·서명 위험의 기존 fail-closed 계약 유지.
2. **USR-13** 같은 파일: 카드번호 형식 후보를 Luhn 체크섬으로 검토. 원문 카드번호는 보고서로 전달하지 않고, 기존 페이지별 후보 건수·마스크 포함 여부만 보고. 이미지 후보·숨김 레이어·완전 삭제 보증 아님.
3. **USR-16 Word** `src/assets/sunrise-office-export.js`와 `src/editor/index.html`: 페이지별 1·2·3단을 보수적으로 자동 판정하여 선택형 Word 변환. 두 모델 이상으로 해석되면 실패, 이미지/제목 혼합 레이아웃은 미지원.
4. **USR-16 Excel** 동일 파일: PDF 페이지마다 독립 `xlsx` 워크시트로 출력(최대 50쪽). 셀 내용은 수식이 아닌 `inlineStr` 문자로 처리, 기존 텍스트·열 추정 출력을 그대로 유지.

## 주요 안전 조건

- PDF 원문 편집은 한글 CID 폰트/임베디드 글꼴/서명·양식/임의 TJ 지원하지 않으며, 민감정보 삭제 수단도 아님.
- 카드번호 탐지는 Luhn 유효성 후보에 한정. 실물 개인정보 검출을 보증하지 않으며 이미지 OCR은 제외.
- 자동 Word 단 구분은 좌표가 명확한 문서에 한정하며 모호한 문서는 오류로 종료.
- Excel 페이지별 워크시트 최대 50개, 텍스트 최대 2MiB, ZIP 출력 기존 12MiB 제한 유지.
- 원본 R32-DEV7과 운영 배포본은 변경하지 않았음. `dist/`는 개발 소스를 반영한 새 빌드가 아님.
- 검증 코드는 `tests/r32-dev8-source-expansion.cjs`에 작성하였지만 **실행하지 않음**.
- 빌드, CI, 브라우저 실기검증, GitHub 쓰기, Cloudflare 배포 없음.

## 퍼센트 기록 정책

잠정 퍼센트는 기존 DEV7 기록 대비 확장 범위를 반영한 **개발관리 추정치**다. 모든 기능에 대한 요구사항 정의가 검증된 동일 가중치로 주어진 것이 아니어서, 이 값을 측정된 완료율이나 생산성 지표로 사용하지 않는다. 세부 변경 4건을 별도로 기록한다.
