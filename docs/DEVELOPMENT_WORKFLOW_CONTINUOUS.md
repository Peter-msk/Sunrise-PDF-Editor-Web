# Sunrise PDF Editor Web — 연속 개발·완료 후 일괄 검증 운영 규칙

- 시행: 2026-11-02 (KST)
- 사용자 결정: 기능을 먼저 묶어서 완성한 뒤 일괄적으로 검증한다. 파일 하나 수정할 때마다 CI/Windows 브라우저 검사를 반복하지 않는다.
- 현재 장기 작업 브랜치: `dev/v12-continuous-development-20261102`; 시작 기준은 PR #28의 기능 HEAD. 새로운 기능/수정은 이 브랜치에 누적한다.
- 개발 중에는 **소규모 기능별 Draft PR을 만들지 않는다**. 파일·기능 단위 커밋은 진행할 수 있으나 PR은 기능 묶음이 완성된 뒤 1개로 취합한다.
- 현재 기존 Draft PR #23~#28은 삭제·병합하지 않고 이전 변경의 참조 이력으로 보존한다.
- 검증 구분: (1) 개발 중 = 구현, 오류 가능성 보고, 진행률 유지; (2) 기능 묶음 완성 = 준비 완료 선언, 통합 검증; (3) 검증 성공 = PR 승인/통합 후보; (4) 실무 수용·운영 배포 = 별도 최종 단계.
- 자동 검증 게이트: `.github/workflows/ci.yml`과 `usr14-qpdf-real.yml`은 Draft PR의 모든 검사 job을 건너뛴다. 준비 완료된 PR의 opened/ready_for_review/synchronize/reopened 또는 수동 실행 때 검증한다. 준비 완료 후 수정하면 CI를 다시 해야 한다.
- 진행률 JSON/MD만 바뀌어도 전체 CI가 돌던 경로는 제거했다. 단, 코드 변경에 대한 최종 CI의 `npm run progress:check`는 유지한다.
- `workflow_dispatch`는 워크플로가 기본 브랜치에 등록되기 전까지 GitHub UI에서 수동 실행이 바로 가능하지 않을 수 있다. 실제 검증은 완료 시 ready-for-review PR로 수행할 수 있다.
- **보안·품질 규칙은 생략하지 않는다.** PDF 구조, 개인정보, 서명/양식, OS·브라우저 호환성, 실제 PDF 저장/재열기는 기능 묶음이 완성된 후 검증해야 한다. 기능 미완성/검증 미완성 상태에서 main·Cloudflare·운영 D1에 배포하지 않는다.
- 검증 실행 전까지 신규 파일·기능을 완료/PASS로 주장하지 않는다. 이전 PR에서 확인된 PASS와 이후 미검증 변경은 구별한다.
- 프로젝트 OCR 제외, Cloudflare 사용자 PDF 원문 업로드 금지, 별도 R12 HANCOM 프로젝트와 소스 혼동 금지.
- **매 개발 보고:** 전체 46% 기준과 1~7단계 진행률 (84·62·57·40·31·51·0%), 이번 신규 기능 개발 내용, 테스트/운영 상태 및 다음 작업을 반드시 표시한다. 증빙 없는 단순 커밋으로 백분율을 올리지 않는다.

## 현재 연속 개발 기능 묶음 (완료 시까지 검증 유예)
- **USR-07 원본 주석·검토 의견표 고도화**: 기존 단순 Text/Highlight 원본 주석 수정·삭제(PR #28)와 PDF 검토 의견표 CSV에 원본 PDF 표준 메모·형광펜까지 합산.
- 추가된 독립 모듈: `src/assets/sunrise-comment-report.js`; PDF 주석/삽입 항목 CSV 생성, CSV 주입 문자열 이스케이프 및 Unicode 처리.
- `src/editor/index.html`의 검토 의견표 및 주석 패널 CSV 내보내기를 비동기로 바꾸어 원본 PDF /Text·/Highlight를 전체 페이지에서 수집. 문서가 작업 중 변경되면 중단한다.
- **상태:** 실제 기능 코드 작성 진행, 아직 완료 전, 신규 코드 CI·실무 파일 검증 미실행. 검증은 사용자 지시대로 기능 묶음 작성 완료 뒤 시작한다.
- 이후 단계: 원본 주석 다중 페이지 관리 UX 마무리 → 기능 묶음 완료 선언 → 테스트 작성·검증·통합 수용 → Draft/Ready PR 결정.

## 개발 중: USR-07 주석 관리·검토 의견표 UI 확장

- 원본 PDF 전체 페이지의 Text/Highlight 주석 목록을 한 번 수집하여 문구·쪽번호 검색 및 주석 유형 필터 지원.
- 주석 목록에서 대상 쪽으로 이동하며, 선택한 쪽의 주석 내용을 수정하거나 페이지 주석 참조를 삭제. 저장 전 스냅샷·참조 일치·PDF 구조 검증, Undo 유지.
- 왼쪽 주석 패널에 '원본 주석' 진입 버튼 추가. 삽입 항목이 없더라도 원본 PDF 주석 관리가 가능하도록 안내 개선.
- 검토 의견표 CSV는 원본 PDF 주석과 Sunrise 삽입 항목을 하나의 구조로 수집; 안전한 CSV 처리 모듈 재사용.
- 과도한 문서/주석 수 제한과 상태 변경 시 작업 취소. 새 기능 검증은 묶음 구현 완료 이후 실행.
- 운영 main/Cloudflare/D1 미변경. 전체 46%, 편집 품질 단계 57% 그대로.
