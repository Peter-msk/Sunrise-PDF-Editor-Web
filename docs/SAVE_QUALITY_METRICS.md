# PDF 준비 품질 집계

- 저장 또는 압축 창에서 PDF 준비를 시작한 익명 작업을 기록한다. 준비 완료는 다운로드용 파일 생성이며 디스크 저장 완료를 의미하지 않는다.
- 실패율은 기록된 준비 완료와 실패 중 실패의 비율이다. 취소, 진행 중, 네트워크 유실은 분모에서 제외하며 0건이면 비율을 표시하지 않는다.
- 같은 창에서 실패 직후 다시 준비한 작업만 재시도로 연결한다. 재시도 후 준비 완료 건수는 해당 재시도 중 준비 완료한 건수이고, 실제 사용자의 파일 저장·오류 원인 해결 여부는 알 수 없다.
- 추정치는 보안 설정·네트워크 단절·탭 종료·하루 세션당 40건 제한에 의해 누락될 수 있다. 기존 데이터의 과거 소급 계산은 하지 않는다.
- 기록은 임의 세션·작업 식별자와 결과만 포함하며 파일명, PDF 내용, 오류 텍스트, 계정 식별자는 포함하지 않는다. 세션 정리 시 관련 기록을 함께 삭제한다.
- 적용 순서는 별도 검증 후 `0005_save_quality.sql` → `0006_save_retry_quality.sql`이다. 0006은 0005의 테이블에 열을 추가한다. 운영 DB에 이미 적용된 0004는 재실행하지 않는다. 코드 배포와 스키마의 호환성을 검토하고 백업/복원 절차를 확인한다.
- 운영 적용 전에는 실제 Cloudflare D1, Windows Chrome/Edge, 통계 수집 실패·다음 날 경계 검증이 필요하다.
