# 주요 처리 결과 계측 소스

소스 구현 단계이며 신규 동작·브라우저 검증은 아직 하지 않았다. 0008_operation_metrics.sql 다음에 0009_extended_operation_metrics.sql, 0010_additional_operation_metrics.sql 순서로 적용한 뒤 사용한다. 0009는 기존 레코드를 보존하며 허용 기능 코드를 확장한다.

| 경로 | 시도 시작 | 완료 기준 |
|---|---|---|
| 문서 불러오기 | 바이트에서 문서 열기 함수 진입 | 편집기 문서 등록과 활성화 처리 완료 |
| PDF 병합 | 2개 이상 대상을 지정하고 병합 실행 | 결과 PDF 생성 및 선택된 후속 열기/다운로드 요청 완료 |
| 페이지 분할 | 전체 페이지 분할 함수 진입 | 개별 PDF 생성과 다운로드 요청 완료 |
| 텍스트 추출 | 텍스트 추출 함수 진입 | 텍스트 결과 창 생성 |
| 문서 검색 | 문서와 비어 있지 않은 검색어가 있는 검색 시작 | 검색 결과 처리 완료(0건 포함) |
| 기존 북마크 수정 | 수정 가능한 문서의 기존 북마크 수정 시작 | 변경 저장 및 화면 갱신 |
| 자동 북마크 분석 | 텍스트 기반 제목 분석 시작 | 분석 완료 또는 후보 추가; 사용자 거절은 취소 |
| 페이지 복제/삭제 | 해당 편집 함수 진입 | PDF 데이터와 화면 갱신 완료 |
| 페이지 회전 | 사전 조건 확인 후 회전 시작 | PDF 회전 및 화면 갱신 완료 |
| 양식 생성/값 수정 | 해당 PDF 양식 처리 함수 진입 | 수정된 PDF 바이트 생성 완료 |
| 본문 형광펜 | 유효한 검색 위치의 형광펜 적용 시작 | PDF 주석 및 화면 갱신 완료 |
| 일괄 압축/표시 | 각 파일의 처리 시작 | 해당 파일 결과 생성·콜백 처리 완료 |
| 수동 북마크 추가 | 유효한 문서에서 추가 실행 | 북마크 등록·목록 갱신 완료 |
| 페이지 삽입/추출/순서 변경 | 실제 실행 함수 진입 | 문서 변경 또는 추출 PDF 생성·다운로드 요청 완료 |
| 페이지 클립보드 복사 | 선택 페이지 복사 함수 진입 | 내부 클립보드 PDF 생성 완료 |
| 오버레이 삽입/편집/복제/삭제 | 실제 변경 실행 | 삽입 항목과 화면 상태 갱신 완료 |
| 일괄 분할/병합 | 일괄 실행 시작 | 결과 생성 종료; 분할 일부 실패는 해당 실행 실패로 표시 |

저장 준비는 기존 별도 계측을 유지한다. 클릭 수를 작업 시도 수로 간주하지 않는다. 불러오기에는 내부 생성 PDF와 최근 문서를 여는 경로도 포함된다. 사전 파일 읽기/크기 검사에서 실패한 경우는 함수 진입 전이므로 이 집계에 포함되지 않는다.

작업별 임의 ID, 익명 탭 세션, KST 일자, 고정 기능 코드와 결과만 저장한다. 파일명·문서 바이트·추출 텍스트·오류 전문은 저장하지 않는다. 탭 세션당 하루 100건 상한이며 네트워크 단절과 종료로 일부 기록이 누락될 수 있다.

실패 비율은 기록된 완료와 실패를 분모로 사용한다. 취소·정책상 중단·결과 미확인은 별도 표시한다. 집계는 최근 14일이며 익명 세션 삭제 시 관련 작업 기록을 함께 삭제한다.

고정 기능 코드는 26개다. 위치 지정 대기 자체는 시도로 세지 않고 실제 배치 시점에 기록한다. 삽입 분류에는 표·페이지 번호·머리말/꼬리말도 포함된다. 양식 완료는 결과 PDF 바이트 생성 단계이며 편집기 적용·파일 다운로드 완료와 다르다. 일괄 실행 전에 거부된 파일 구성/설정은 계측 시작 전이므로 집계에서 제외한다. 검색 위치 분석이 일부 실패해 페이지 수준 결과로 대체된 경우는 검색 자체의 완료로 기록한다. 새 작업을 계측할 때 실제 처리 경계와 정책 중단을 구분해야 한다. 운영 배포 전 신규 스키마 및 정상·오류·취소·중복·자정 경계·권한 검증을 진행한다.


## 수집 Worker 버전별 조회

0013_operation_versions.sql 이후 시작 기록에 서버 바인딩의 Worker 버전 ID를 저장한다. 클라이언트가 전송한 버전 값은 사용하지 않는다. 종료 이벤트가 다른 Worker 버전에서 접수되더라도 시작 버전은 유지한다. 기존 기록과 버전 바인딩이 없는 기록은 `unknown`으로 남기며 과거 값을 추정하지 않는다. 이는 편집기 HTML/JavaScript 빌드 버전 추적이 아니다.

- 관리자 주요 처리 결과와 저장 준비 결과에 공통 7·14일 및 수집 Worker 버전 필터를 제공한다.
- `/api/admin/operations`와 `/api/admin/save-quality`는 `days=7|14`, 선택적 `version=UUID|unknown`을 받는다. 생략 시 14일·전체 버전이다.
- `/api/admin/operations.csv`는 같은 필터로 26개 주요 경로와 저장 준비 1개 행을 내보낸다. 취소와 미확인은 따로 기록하고 실패 비율의 분모에서 제외한다. 개인정보나 문의 내용은 넣지 않는다.
- 버전 목록은 해당 기간의 작업 시작 기록이 있는 버전이며 최대 200개다. 버전 목록 제한과 실제 집계 범위는 별개다.
- 조회 범위를 빠르게 바꿀 때 이전 응답이 새 화면을 덮지 않도록 요청 순서와 범위를 확인한다.

`tests/admin-version-retention-contract.cjs`에 버전 귀속·결과 불변성·필터·CSV·서버 신뢰경계의 실행 가능한 회귀 코드를 작성했다. 현재 소스 우선 단계에서는 이 테스트를 실행하지 않았다.
