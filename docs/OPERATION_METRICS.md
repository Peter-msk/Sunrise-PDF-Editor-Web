# 주요 처리 결과 계측 소스

소스 구현 단계이며 신규 동작·브라우저 검증은 아직 하지 않았다. 0008_operation_metrics.sql 다음에 0009_extended_operation_metrics.sql, 0010_additional_operation_metrics.sql 순서로 적용한 뒤 사용한다. 0009는 기존 레코드를 보존하며 허용 기능 코드를 확장한다.

| 경로 | 시도 시작 | 완료 기준 |
|---|---|---|
| 문서 불러오기 | 바이트에서 문서 열기 함수 진입 | 편집기 문서 등록과 활성화 처리 완료 |
| PDF 병합 | 2개 이상 대상을 지정하고 병합 실행 | 결과 PDF 생성 및 선택된 후속 열기/다운로드 요청 완료 |
| 페이지 분할 | 전체 페이지 분할 함수 진입 | 개별 PDF 생성과 다운로드 요청 완료 |
| 텍스트 추출 | 텍스트 추출 함수 진입 | 텍스트 결과 창 생성 |
| 문서 검색 | 문서와 비어 있지 않은 검색어가 있는 검색 시작 | 검색 결과 처리 완료(0건 포함) |
| 기존 북마크 수정 | 수정 가능한 문서의 기존 북마크 수정 시작 | 변경 저장 및 화면 갱신 |
| 자동 북마크 분석 | 텍스트 기반 제목 분석 시작 | 분석 완료 또는 후보 추가; 사용자 거절은 취소 |
| 페이지 복제/삭제 | 해당 편집 함수 진입 | PDF 데이터와 화면 갱신 완료 |
| 페이지 회전 | 사전 조건 확인 후 회전 시작 | PDF 회전 및 화면 갱신 완료 |
| 양식 생성/값 수정 | 해당 PDF 양식 처리 함수 진입 | 수정된 PDF 바이트 생성 완료 |
| 본문 형광펜 | 유효한 검색 위치의 형광펜 적용 시작 | PDF 주석 및 화면 갱신 완료 |
| 일괄 압축/표시 | 각 파일의 처리 시작 | 해당 파일 결과 생성·콜백 처리 완료 |
| 일괄 분할/병합 | 일괄 실행 시작 | 결과 생성 종료; 분할 일부 실패는 해당 실행 실패로 표시 |

저장 준비는 기존 별도 계측을 유지한다. 클릭 수를 작업 시도 수로 간주하지 않는다. 불러오기에는 내부 생성 PDF와 최근 문서를 여는 경로도 포함된다. 사전 파일 읽기/크기 검사에서 실패한 경우는 함수 진입 전이므로 이 집계에 포함되지 않는다.

작업별 임의 ID, 익명 탭 세션, KST 일자, 고정 기능 코드와 결과만 저장한다. 파일명·문서 바이트·추출 텍스트·오류 전문은 저장하지 않는다. 탭 세션당 하루 100건 상한이며 네트워크 단절과 종료로 일부 기록이 누락될 수 있다.

실패 비율은 기록된 완료와 실패를 분모로 사용한다. 취소·정책상 중단·결과 미확인은 별도 표시한다. 집계는 최근 14일이며 익명 세션 삭제 시 관련 작업 기록을 함께 삭제한다.

새 북마크 수동 추가, 페이지 순서 변경/추출/삽입, 일반 삽입 오버레이 전체의 계측은 아직 제공하지 않는다. 양식 완료는 결과 PDF 바이트 생성 단계이며 편집기 적용·파일 다운로드 완료와 다르다. 일괄 실행 전에 거부된 파일 구성/설정은 계측 시작 전이므로 집계에서 제외한다. 검색 위치 분석이 일부 실패해 페이지 수준 결과로 대체된 경우는 검색 자체의 완료로 기록한다. 새 작업을 계측할 때 실제 처리 경계와 정책 중단을 구분해야 한다. 운영 배포 전 신규 스키마 및 정상·오류·취소·중복·자정 경계·권한 검증을 진행한다.
