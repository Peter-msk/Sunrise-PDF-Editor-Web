# 주요 처리 결과 계측 소스

소스 구현 단계이며 신규 동작·브라우저 검증은 아직 하지 않았다. 0008_operation_metrics.sql 적용 후 사용한다.

| 경로 | 시도 시작 | 완료 기준 |
|---|---|---|
| 문서 불러오기 | 바이트에서 문서 열기 함수 진입 | 편집기 문서 등록과 활성화 처리 완료 |
| PDF 병합 | 2개 이상 대상을 지정하고 병합 실행 | 결과 PDF 생성 및 선택된 후속 열기/다운로드 요청 완료 |
| 페이지 분할 | 전체 페이지 분할 함수 진입 | 개별 PDF 생성과 다운로드 요청 완료 |
| 텍스트 추출 | 텍스트 추출 함수 진입 | 텍스트 결과 창 생성 |

저장 준비는 기존 별도 계측을 유지한다. 클릭 수를 작업 시도 수로 간주하지 않는다. 불러오기에는 내부 생성 PDF와 최근 문서를 여는 경로도 포함된다. 사전 파일 읽기/크기 검사에서 실패한 경우는 함수 진입 전이므로 이 집계에 포함되지 않는다.

작업별 임의 ID, 익명 탭 세션, KST 일자, 고정 기능 코드와 결과만 저장한다. 파일명·문서 바이트·추출 텍스트·오류 전문은 저장하지 않는다. 탭 세션당 하루 100건 상한이며 네트워크 단절과 종료로 일부 기록이 누락될 수 있다.

실패 비율은 기록된 완료와 실패를 분모로 사용한다. 취소·정책상 중단·결과 미확인은 별도 표시한다. 집계는 최근 14일이며 익명 세션 삭제 시 관련 작업 기록을 함께 삭제한다.

아직 검색·북마크·모든 페이지 편집·주석·양식·일괄 처리 전체의 계측을 제공하지 않는다. 새 작업을 계측할 때 실제 처리 경계와 정책 중단을 구분해야 한다. 운영 배포 전 신규 스키마 및 정상·오류·취소·중복·자정 경계·권한 검증을 진행한다.
