## 갱신 정책

1. 기능·테스트·실사용·배포 증빙이 생길 때 관련 원천 JSON만 갱신합니다.
2. `npm run progress:write`로 표를 생성하고 `npm run progress:check`로 위조/불일치를 방지합니다.
3. 매 개발 보고마다 기능별 변경률·7개 단계·총괄 진행률을 다시 표시합니다.
4. 미확인 상태는 완료로 기록하지 않고, 검증 실패 시 점수를 낮출 수 있습니다.
5. **완료 100%**는 전체 계획 수용 기준 충족 및 운영 배포 확인 뒤에만 부여합니다.
