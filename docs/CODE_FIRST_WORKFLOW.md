# 소스 구현 우선 진행 기준

2026-11-01 사용자 결정. 기존 문서의 기능별 전체 검사·브라우저 검사 선행 절차는 아래 순서로 변경한다.

1. 관리자 ADM-01~14 전체의 남은 소스와 API/UI 연결을 먼저 구현한다.
2. 기능 검증을 항목별로 진행한다.
3. 브라우저와 실제 사용 환경 검증을 진행한다.
4. 발견된 오류를 수정하고 영향 범위를 다시 확인한다.
5. 운영 반영 및 인수 확인을 진행한다.

구현 중에는 문법, 누락된 연결과 명백한 오류만 필요한 범위에서 확인한다. 기능/브라우저 검증의 실행·완료는 별도로 기록한다. 검증하지 않은 기능을 통과 또는 공개 준비 완료로 표시하지 않는다.

소스 구현률은 development-progress.json의 implementation 값 평균으로 표시한다. 기존 가중 진행률은 유지하되 소스 구현률과 섞지 않는다. 소스 구현률도 구현 범위에 대한 잠정 관리 점수이다.

이번 단계는 feat/admin-fast-development-20261101에서 계속한다. 새 기능의 전체 회귀검사와 브라우저 검사는 관리자 소스 구현 단계 종료 후 진행한다. OCR은 계속 제외한다.

## 잔여 소스 범위

- 저장 외 주요 작업의 실행·결과 계측 및 관리자 집계
- 방문/활성시간 정의에 맞춘 추가 집계
- 실제 배포 성공·실패 및 배포 시각을 제공할 인증된 정보 경로
- 운영 보존·백업/격리 복원 절차 및 필요한 도구
- 관리자 운영 화면·문의·공지·업데이트·CSV·보안 연결의 누락 보완

외부 서비스 권한이나 운영 환경이 필요한 항목은 의존성을 명시한다. 실제 연결이 없으면 임의 데이터로 완료를 표시하지 않는다.
