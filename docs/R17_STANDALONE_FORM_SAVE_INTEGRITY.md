# R17 — 독립 PDF 양식 저장 후 검증 강화 (USR-10 / USR-18)

- 기준: R16 코드 수정·CI PASS 브랜치에서 분기한 `dev/r17-form-save-integrity-20261103`.
- 대상 코드: `src/assets/sunrise-pdf-form-tools.js` (별도 PDF 파일을 입력받는 독립 양식 도구).
- 기존 동작: 새 PDF를 저장한 뒤 다시 읽어 페이지 개수·양식 필드 *이름*만 비교.
- 변경 동작: 입력 PDF의 전체 페이지 회전·MediaBox/CropBox/BleedBox/TrimBox/ArtBox 좌표와 크기를 독립 스냅샷으로 보관하고, 저장된 PDF 재열기 뒤 허용 오차 0.01pt 이내로 비교한다.
- 변경 동작: 필드 순서·이름·유형·텍스트/체크박스/드롭다운 값·드롭다운 선택지·읽기 전용 플래그를 저장 직전과 재열기 뒤 비교한다.
- 불일치 시 오류를 던지고 **결과 바이트를 반환하지 않는다**. 필드 입력값 자체는 오류 메시지·진행 로그로 기록하지 않는다.
- 취소 요청 시 저장 전/후·재검증 단계에서 결과 반환을 중단한다. 원본 파일 불변 정책 유지.
- 새 회귀 검사: `tests/standalone-form-save-integrity.cjs` — 실제 2쪽 PDF 편집·값/페이지 박스 확인·입력 원본 불변 및 8개 오류 주입·취소.
- 이 변경으로 기존 활성 문서 편집기 전체 PDF 저장 루틴의 안전성이 증명되는 것은 아님. `USR-10` 독립 양식 도구 및 연계된 `USR-18` 저장 검증 범위만 강화한다.
- 서명 인증, 암호화, 원문 완전 삭제, OCR 등 다른 기능은 구현·완료로 기록하지 않음.
- 신규 기능 점수는 검증 증빙 확인 전 상향하지 않으며, 운영 `main`·Cloudflare/D1 배포 변경은 별도 승인 경로로만 진행한다.
