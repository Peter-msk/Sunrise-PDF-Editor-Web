# R34-DEV1 개발 인계

R33-DEV1 소스를 기반으로 작업했다. 전체 미구현 종료본 또는 최종 배포물은 아니다.

## 실제 변경

- `sunrise-pdf-form-tools.js`: 페이지·위젯·필드 트리에 동일한 객체 복사기를 사용한다. 선택 페이지에 없는 위젯은 필드 트리에서 제외한다. 문서별 네임스페이스와 기본 외관 리소스 이름으로 충돌을 격리한다. 첨부 이름 트리 및 AF 연결을 보존한다. 실패한 출력 문서는 버리고 입력을 덮어쓰지 않는다. 아직 게시하지 않은 출력 문서만 전달해야 하며 실패 시 그 출력 문서를 재사용하지 않는다.
- `sunrise-content-editor.js`: Form 호출 경로별로 리소스와 스트림을 복제해 선택 호출만 수정한다. 내장 고정 길이 CID CMap, Identity-V, 따옴표 텍스트 연산자를 지원한다. 클리핑 경로 변경에는 q/Q를 추가하지 않아 원래 클리핑 수명이 유지된다.
- `sunrise-pdf-cms.js`: 원본 바이트 뒤에 수정 객체·교차 참조·Prev 트레일러를 추가하는 증분 서명. 최종 개정과 이전 개정 각각의 CMS 및 ByteRange를 확인한다. 인증/필드 잠금과 지원하지 않는 서명은 거부한다. 일반 승인 서명 지원을 PAdES 적합성으로 표시하지 않는다.
- `sunrise-pki.js`: P12/PFX 추가 서명 옵션을 PEM 서명 엔진에 전달한다. 인증서 및 개인키의 서버 전송·영속 저장은 추가하지 않았다.
- `sunrise-office-export.js`: 연결된 표 선을 분리해 다중 표를 처리하고, 표가 없는 페이지 및 표 사이 원문을 유지한다. 혼합 Word는 텍스트 상자·실제 표 셀·개별 이미지로 저장한다. 편집 가능한 변환은 페이지 전체 PNG를 사용하지 않는다. 기존 원본 모양 이미지 Word는 별도 메뉴로 유지한다.
- `sunrise-embedded-images.js`: 이미지 변환 행렬과 개별 PNG를 추출한다. 잘림·기울임·회전·일부 그룹은 정확성을 위해 명시적으로 거부한다. 임시 캔버스는 인코딩 후 해제한다.
- `sunrise-outline-transfer.js`: 북마크 이식 깊이 32단. 저장 측도 32단을 허용한다. 자동 제목 추론/수동 생성 UI는 기존 4단 정책을 유지한다.
- `src/editor/index.html`: 위 기능의 메뉴·파일명·진행·취소·변경 문서 감지를 연결했다. FreeText 한글 외관을 다시 만들고, 주석 삭제 시 하위 답글·팝업만 함께 제거한다. 연결된 잠긴 항목이 있으면 삭제 전에 중단한다.

## 확인 범위

`R34_VALIDATION.json`의 기능 19개 검사 묶음과 문법 8개 검사가 모두 통과했다. 기능 수와 검사 묶음 수는 별개다. 원본 바이트 불변, 다른 Form 호출/페이지 불변, 양식 재편집, 첨부 바이트, 서명 변조 거부, 별도 OpenSSL CMS 검증, OOXML ZIP/XML 파싱 등을 포함한다.

초기 검사에서 AF 첨부 연결 보호 규칙이 일반 첨부까지 막았다. AF 파일 명세를 같은 복사기로 보존하도록 고쳤고 해당 검사를 다시 실행했다. 이미 통과한 비영향 검사는 중복 실행하지 않고 증거를 유지했다.

## 배포 전 남은 단계

- 현황표의 네 가지 핵심 미구현 범위를 해결하거나, 별도 요구 변경으로 릴리즈 지원 범위를 확정해야 한다. 이번 작업에서 요구 범위를 임의로 축소하지 않았다.
- `npm ci --ignore-scripts`로 고정 의존성을 설치하고 기존 릴리즈 절차에 따라 전체 회귀·진행표·빌드를 확인해야 한다.
- 이번 새 검사도 기본 `npm test`의 후반에 연결했다. 기존 검사와 중복되는 부분은 제외하고 신규 R33/R34 검사만 연결한다.
- `dist/`는 과거 배포물이다. 원본 소스 빌드 전에는 이 폴더를 새 릴리즈로 배포하면 안 된다.
- Word/Excel·독립 PDF 뷰어·브라우저 Worker 실제 로딩·Android/iOS·실무 문서의 수용 확인이 필요하다.
- 운영 D1 복구 증거와 기존 수동 릴리즈의 CI 조건은 유지한다. GitHub·Cloudflare·D1에는 쓰지 않았다.

이번 환경에는 프로젝트가 고정한 terser가 설치되어 있지 않다. 이전 방침에 따라 빌드·CI·배포는 수행하지 않았다. 이를 기능 검증 PASS로 치환하지 않는다.
