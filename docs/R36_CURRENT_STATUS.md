## 반드시 구분할 미완료 게이트

1. **구현 한계:** 외부/상속 CMap과 범용 원문 재흐름, XFA 자동 계산/스크립트 양식, PAdES LT/LTA, 임의 PDF의 고충실도 Office 복원은 지원 완료로 선언할 수 없습니다. OCR은 범위에서 제외합니다.
2. **정식 빌드:** 잠긴 `terser@5.51.2`, `pdfstudio@0.4.0`, `node-forge@1.4.1` 의존성을 `npm ci`로 설치해 `npm run build`를 재실행해야 합니다. 검증용 미압축 빌드는 운영 배포 금지입니다.
3. **브라우저·Office·모바일:** 현재 실행 환경 Chromium이 로컬 주소 및 파일 URL을 관리 정책으로 차단했으므로 실제 웹 동작을 PASS로 기록하지 않습니다.
4. **운영 배포:** GitHub main/CI, Cloudflare Worker, 원격 D1 및 격리 복원은 이번 개발에서 변경/검증하지 않았습니다.

**마감 원칙:** 이미 통과한 비영향 검사는 반복하지 않고, 기능 수정과 영향을 받는 경로만 우선 검증합니다. 다만 실제 운영 배포 승인은 잠긴 의존성 기반 정식 빌드와 필수 CI 및 백업 복구를 통과한 뒤에만 가능합니다.
