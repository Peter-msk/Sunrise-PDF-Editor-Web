## 코드 구현이 남은 핵심 범위

1. 외부/상속/가변 길이 CMap과 모든 원본 글꼴, 임의 문단 재흐름을 포함한 범용 원문 편집.
2. XFA, 자동 계산/스크립트, 태그·특수 구조를 유지하는 양식과 페이지 조작.
3. OCSP/CRL·신뢰 타임스탬프·PAdES LT/LTA와 변경 제한 인증 서명.
4. 원본 글꼴·벡터 도형·회전/잘림 이미지·문단 흐름을 정확히 복원하는 범용 Office 변환.

이 네 항목은 테스트 대기가 아니라 실제 미구현을 포함한다. Android/iOS·독립 뷰어·실무 PDF 수용과 배포 검증은 별도 확인 대기다. 기존 관리자 ADM-01~14는 이번에 수정하지 않았고, 과거 작성 관리값을 새로운 운영 검증으로 바꾸지 않았다.

검사 원문: `R34_VALIDATION.json`. 상세 인계: `R34_IMPLEMENTATION.md`. 실행 명령: `npm run test:r34` (Node 18+·OpenSSL·Python 3 필요; Python 실행파일은 `SUNRISE_PYTHON`으로 지정 가능).
