# R23 — USR-13 민감정보 마스크 픽셀 경계 및 불투명도 검증

## 기존 확정 개발계획
v1.2 USR-13 민감정보 완전 삭제의 제한적 래스터 기반 새 PDF 출력 경로를 개선한다. 자동 개인정보 식별이나 인증된 완전 삭제를 구현했다고 주장하지 않는다.

## 문제와 수정
- 기존 사각형 출력은 `floor(x*scale)`과 `ceil(width*scale)`을 조합하여 소수점 좌표에서 우측 또는 하단 경계에 1px 미만의 **원본 이미지 노출** 가능성이 있었다. 이제 왼쪽/위는 내림하고 **오른쪽/아래 끝 좌표는 따로 올림**해 전체 사각형을 덮는다.
- `ctx.fillRect` 호출만으로 실제 픽셀이 덮였는지 보장하지 않는다. 검은 마스크 렌더 후 **네 모서리+중앙의 실제 캔버스 픽셀 RGB/불투명도**를 `getImageData`로 확인하고, 실패하거나 읽을 수 없는 렌더러에서는 PDF 결과 생성을 거부한다.
- 위 검증은 단일 페이지 `exportMaskedPage` 및 다중 페이지 `exportMaskedPages`에 공통 적용하고, 이미 사용 중인 PDF.js와 pdf-lib만 재사용한다. 신규 의존성·네트워크·운영 DB 변경 없음.
- 기존 마스크 한도·전체 페이지 포함 옵션·출력 PDF의 원본 텍스트·첨부·양식·주석 비이식 계약은 유지한다.

## 검증
- 단일 페이지와 여러 페이지의 기존 회귀에서 실제 마스킹 색상의 픽셀 읽기를 모델링한다.
- 소수점 입력 사각형을 2x 스케일에서 우측/하단을 포함해 그리는지 검사한다.
- 불투명한 검은색으로 렌더되지 않은 경우 **출력 PDF를 반환하기 전에** 오류가 발생하는지 검사한다.
- Node 계약검사 및 Linux Chromium/Windows Chrome·Edge PDF 저장 회귀를 개발 PR에서 점검한다.

## 엄격한 범위 제한
이 검사는 샘플링 5개 픽셀의 검증이다. 마스크 전체의 모든 픽셀, 외부 파일에 있는 다른 페이지/첨부, 원문 검색/복사 검사와 독립적인 완전 삭제 보증이 아니다. 사용자가 지정하지 않은 민감정보의 자동 검출도 하지 않는다. 실제 스캔본·도면·모바일 실기기 및 법률·보안 인증은 미수행이며 기능 명칭의 '완전 삭제'와 **기술적 인증 상태를 명확히 구분**한다.
