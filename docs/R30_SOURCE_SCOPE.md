# R30 변경 경계 / 로컬 소스 작업

## 대상

- 기존 GitHub PR #57 R26 HEAD `5781b9546b827a38007bd85c7fffb0a487dd1a4a` 읽기 전용 참조
- `src/editor/index.html` 한 파일의 다섯 사용자 기능 영역에서만 안전성 관련 변경
- 로컬 사용자 데이터나 PDF는 포함·변경·전송하지 않음

## 추가한 동작(코드 작성 단계)

**USR-01 병합:** 저장 직전 전체 페이지 수 재확인, 실제 PDF 바이트를 PDFDocument.load로 다시 읽어 페이지별 Media/Crop/Bleed/Trim/Art Box 및 회전 보존 확인. 거부 시 다운로드하지 않음.

**USR-02 추출:** 실행 시작 원본 상태 스냅샷, 컴파일 후와 다운로드 전 비교, 실행 중 작업 잠금. 실제 결과 PDF 직렬화 후 다시 읽어 페이지 기하정보 검사. 실패 시 사용자 메시지와 잠금 해제.

**USR-03 페이지 삭제/재정렬:** 문서 작업 상태 잠금 및 실행 시점의 PDF.js reader 기록. PDF 저장 뒤 실제 바이트 재열기 검사, PDF.js로 읽힌 다음에만 상태 변경·Undo 기록. 오류의 사용자 표시·잠금 정리.

**USR-04 텍스트 삽입:** 빈 문구 삽입 금지, 페이지 크기 미확인·극소형 페이지의 위치 오배치 차단.

**USR-06 표:** 길이 외에 제어문자, 손상 Unicode 서러게이트 쌍을 확인.

## 한계

- 시각 렌더링 동일성이나 페이지 콘텐츠의 바이트 단위 완전한 동등성 검사는 추가하지 않음.
- 원본 PDF 고유 양식, 특수 북마크, 전자서명 보존의 전체 보장은 기존 엔진의 제한을 따른다.
- 로컬 패치 스크립트는 **코드 변경 작업물**로만 작성, 실행하지 않음. 내용의 구문·실행 및 브라우저 실기검증 미완.
- `100%`는 실제 사용자 요구사항 전체가 코드로 구현되고 실기검증·안정화된 후의 판정이며 이번 보고서에는 없다.
