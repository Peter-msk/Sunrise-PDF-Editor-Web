# USR-10 — 표준 PDF 양식 다중 필드 일괄 입력 (코드 구현)

- 개발 브랜치: `dev/v12-continuous-development-20261102` (연속 기능 개발 방식).
- 기존 "PDF 양식 입력값 수정"과 "PDF 양식 입력칸 만들기" 메뉴는 그대로 보존.
- 신규 메뉴 "PDF 양식 여러 칸 한번에 입력": 최대 100개 필드 중 지원하는 일반 텍스트/체크박스를 표시; 여러 값의 변경분만 추출하여 한 번에 적용.
- 읽기 전용 값 수정 불가. XFA, 인증 서명·문서 권한, 일반 PDF 서명 필드 수정 불가. 비밀번호/서식 있는 텍스트/파일선택과 미지원 종류는 일괄 편집에 포함하지 않음.
- 모든 필드 유효성 확인이 통과한 후에만 같은 PDF 문서에 수정 적용. 여러 한글 필드 값을 위한 폰트를 **한 번 임베딩**해 PDF 재직렬화.
- 페이지 구조·주석·카탈로그 저장 사전 검사를 통과하고 원래 문서 상태가 유효하면 Undo 스냅샷 1개 및 PDF.js 재열기 연결.
- 사용자 PDF 원문 서버 업로드 없음. 작업 중 문서/모달 변경 시 적용 취소.
- 최종 일괄 검증 대상: `tests/bulk-form-fields.cjs` (한글·필드 다건 저장·한글 글꼴 한 번·읽기 전용·중복·서명·XFA·원본 불변); 기존 `tests/create-form-field.cjs`, `tests/form-save-roundtrip.cjs` 및 브라우저 업로드/저장·재열기.
- **코드 작성은 완료, CI/실무 PDF 현장 검증은 미실행**. 사용자 지시에 따라 전체 기능 묶음 완료 이후 검증.
- 개발 진행률은 이전 증빙 기반 전체 **46%**로 유지. 작성만으로 검증 점수를 상향하지 않음.
