# Sunrise PDF Editor — 관리자 우선 개발 및 완료 기준

관리자 14개 항목을 **사용자 기능보다 먼저** 구현·검증한다. 사용자 PDF 기능 추가는 관리자 수용 기준을 충족할 때까지 보류하며 OCR은 제외한다.

## 이번 관리자 집중 개발 B2

- ADM-01/02/03: 방문 세션·활성 편집시간·오류 건수의 7·14·30일 기간 필터.
- ADM-04/12: 실제 저장된 익명 세션의 최근 14일 오류 발생 비율. 세션 데이터는 14일 보존되므로 30일 세션 비율을 생성하지 않는다. 기능별 실행 성공률·완료율도 아직 계산할 수 없다.
- ADM-14: 48시간 이상 미확인 문의와 오류 세션 비율 15% 이상(최소 10개 세션 중 3개 오류 세션)의 관리자 내부 경고.
- 검증: 53개 Node 테스트, 기존 PDF 저장 Chromium 실기, **신규 관리자 UI Chromium 모의 API 시험**. 인증 우회나 운영 D1 실제 조회가 아님.

## B3 관리자 업무 흐름 검증 (2026-10-31)

- 문의(ADM-05): 검색 → 문의 선택 → 상태/메모 저장 후 상세 패널 유지 → 상태 이력 즉시 재조회. 이전에는 저장 직후 상세 패널이 닫혀 결과 확인이 어려웠으나 수정함.
- 공지(ADM-06), 업데이트(ADM-07): **SQLite의 실제 공개 조회**로 최초 게시 후 7일 지난 데이터 제외. 수정·숨김·재게시해도 최초 게시일이 변경되지 않으며 만료 자료는 관리자만 조회 가능. Chromium 모의 API에서 CRUD 및 만료 표기도 검증.
- 통계 CSV(ADM-13): 최근 30일 일별 익명 집계, UTF-8 BOM 바이트, 비로그인 접근 차단, Chromium 파일 실제 다운로드를 검사.
- 테스트: `tests/admin-publication-csv-lifecycle.cjs`와 `tests/browser-admin-workflows.cjs`, 기존 Node 53개 → 54개, Chromium 브라우저 업무 흐름 시험 추가.
- 최종 CI: https://github.com/Peter-msk/Sunrise-PDF-Editor-Web/actions/runs/41211809206 — Node 계약/릴리스 빌드/진행률 검사/브라우저 업무 흐름 PASS.
- **한계:** 테스트는 공개 피드·관리자 API SQLite 계약과 모의 API Chromium 화면. 실제 관리자 비밀번호 로그인, 운영 Cloudflare D1, 외부 Excel 사용, 실제 배포/롤백 수용 검증은 남아 있으므로 ADM 14개 중 최종 수용 완료는 0개로 유지.
- 관리자 단계 점수 **53%**, 7단계 전체 잠정 점수 **32%**. 사용자 기능은 이번 작업에서 수정하지 않음. OCR 제외.

## B4 관리자 계정 보안·보존/복원 검증 (2026-11-01)

- **ADM-10**: 90일 초과 문의 본문뿐 아니라 연결된 `inquiry_audit` 이력도 함께 정리. 고아 이력 정리, 14일 익명 세션·로그인·전송 제한 기록을 기존 정책에 따라 정리. 실제 SQLite 마이그레이션과 합성 데이터로 정리 경계·최근 데이터 보존·멱등성을 검증.
- **ADM-10 로컬 복원**: 임시 SQLite `VACUUM INTO` 스냅샷을 새 데이터베이스로 다시 열어 핵심 테이블 건수와 `PRAGMA integrity_check`를 검증. **운영 Cloudflare D1에 대한 백업·복구를 실행한 것은 아님**.
- **ADM-11**: 실제 HTTPS 시험 서버 + Chromium + 로컬 SQLite 계정 등록/브라우저 2개 로그인/Secure HttpOnly 쿠키/비밀번호 변경 후 전체 세션 폐기/새 비밀번호 재로그인/로그아웃 연속 흐름 PASS.
- `src/admin-retention.mjs`, `src/worker.mjs`, `tests/admin-retention-restore.cjs`, `tests/browser-admin-auth.cjs` 및 CI/운영 체크리스트 추가. **55개 Node 검사와 Chromium 4종류 브라우저 시나리오 통과**.
- 상세 출시 수용 정책: `docs/ADMIN_SECURITY_RETENTION.md`. 실제 운영 관리자 계정·Cloudflare 도메인·백업/복원·롤백 승인 전에는 관리자 최종 수용 완료 0/14를 유지.
- 관리자 단계 **56%**, 7단계 전체 **33%**. 사용자 편집기 기능·OCR 미변경.

## B5 서비스 상태·Worker 버전·운영 알림 개선 (2026-11-01)

- **ADM-08**: 기존 관리자 전용 `GET /api/admin/health`의 Worker/D1 연결 응답을 유지하고, D1 정상(200)·저하(503)·복구를 실제 Chromium 화면에서 검증. DB 오류 전문은 공개하지 않으며 D1 자체가 완전히 끊기면 인증 단계도 실패할 수 있어 외부 가동률 감시와 다름.
- **ADM-09**: Cloudflare 공식 `[version_metadata]` 바인딩을 `wrangler.toml`에 추가. Worker **버전 ID** `id`, 버전 태그 `tag`, **버전 생성 시각** `timestamp`를 인증된 관리자 화면에 표시. 사용자가 설정한 `RELEASE_VERSION`은 태그가 없을 때만 대체 표시. **Worker 버전 생성시각은 운영 배포시각이나 배포 이력이 아니다.**
- **ADM-14**: 운영 확인 알림 중복 제거, 확인 개수 표시, 상태·품질·방문 통계 동시 새로고침. D1 연결 불량 경고가 복구 후 제거되는지 Chromium 모의 API로 테스트. 백그라운드 감시·외부 푸시·알림 이력은 미개발.
- 검사: Node 계약 검사 총 **56개**, 기존 PDF 및 관리자 Chromium 회귀 시나리오 유지. `wrangler.toml` 수정 시 CI가 실행되도록 경로 추가.
- **실제 Cloudflare Worker를 배포하거나 운영 관리자 계정/실제 D1을 변경하지 않음.** 향후 배포 후 바인딩이 정상적으로 제공되는지 운영 계정에서 최종 확인해야 한다.
- 관리자 단계 **60%**, 7단계 총괄 **33%**. 관리자 수용 완료 항목 **0/14** 유지, 사용자 PDF 기능은 수정하지 않음. OCR 제외.
- Cloudflare 출처: https://developers.cloudflare.com/workers/runtime-apis/bindings/version-metadata/

## 관리자 남은 완료 수용 기준

- ADM-01~04/12: 기간별 운영 원천 집계와 품질 지표의 정확성, 실제 로그인한 관리자 UI 테스트.
- ADM-05~07/13: 문의 검색/수정/이력, 게시물 최초 게시 후 7일 표시, 업데이트/통계 CSV 실기.
- ADM-08/09/14: 실제 D1 장애·배포 ID 설정, 알림 오탐/과다발생 검토.
- ADM-10: 보존·백업과 복원 절차 검증.
- ADM-11: 로그인/비밀번호 변경/세션 폐기/인증 속도 제한 검증.

## 보고 방법

장기 7단계 전체 진행률은 관리자 집중 개발 속도를 반영하기 어렵다. 매번 관리자 단계 점수와 **14개 기능별 점수/남은 완료 게이트**, 총괄 점수를 함께 보고한다.

- 관리자 단계 잠정 점수: 60%.
- 전체 7단계 잠정 점수: 33%.
- 실제 관리자 계정으로 수용 및 운영 검증까지 마친 기능 수: 현재 0/14. 이는 구현 기능이 없다는 뜻이 아니며 실제 수용 게이트가 남았다는 의미다.
