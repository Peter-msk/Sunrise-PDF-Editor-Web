# R26 — PDF→Excel 다중 페이지 표 열 정렬·대용량 행 분류

- 적용 위치: 기존 PR #57 개발 브랜치(새 PR 불필요), 기존 Excel 열 추정 명령 유지.
- 변경 목표: 페이지마다 일부 열이 비었을 때 Excel 열 이동 방지, 비정렬 문구 안전 보존, PDF 텍스트 대량 처리.

## 구현
1. 가장 많은 열이 인식된 페이지의 X좌표를 공통 스키마로 사용해, 다른 페이지의 중간 빈 열을 실제 빈 Excel 셀로 유지.
2. 페이지 간 열 기준이 충돌할 경우 자동으로 잘못 합치지 않고 명시적으로 오류를 반환.
3. 중앙 제목·설명 및 다열 표가 없는 페이지는 별도 '비정렬 원문' 열에 표시. 표 데이터의 첫 번째 열로 임의 이동 금지.
4. 텍스트 항목을 정렬하고 인접 기준선으로 묶어 수천 행 문서에서 제곱 시간 행 탐색 제거.
5. 페이지 120장·텍스트 항목 10만 개/페이지·표 열 10개·Excel 3만 행·문자/출력 크기 및 수식 비실행 정책 유지.

## 검증 범위
- Node 집중 회귀: 2/3열 페이지, 중간 빈 열, 비정렬 문구, 일반 텍스트 페이지, 다른 레이아웃 거부, 1800행.
- 브라우저 합성 PDF 2쪽을 통한 다열 XLSX 다운로드 및 실제 셀 좌표 확인.
- 데이터 손실 방지가 우선이며 원본 표 병합·테두리·시각적 스타일의 전체 복원을 약속하지 않음.
- OCR 제외, 서버 PDF 업로드 없음, PDF 원본 수정 없음, 실제 고객 문서·데스크톱 Excel 검증은 별도.
- 과거 PASS를 신규 HEAD의 PASS로 간주하지 않으며, 최종 제품 출고 전 전체 요구 게이트 확인.
